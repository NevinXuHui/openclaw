## 1. 简介

### 1.1 目的

此威胁模型使用专为 AI/ML 系统设计的 MITRE ATLAS 框架,记录 OpenClaw AI agent 平台和 ClawHub Skills 市场的对抗性威胁。

### 1.2 范围

| 组件                  | 包含 | 注释                                          |
| --------------------- | ---- | --------------------------------------------- |
| OpenClaw Agent 运行时 | 是   | 核心 agent 执行、工具调用、会话               |
| Gateway               | 是   | 身份验证、路由、频道集成                      |
| 频道集成              | 是   | WhatsApp、Telegram、Discord、Signal、Slack 等 |
| ClawHub 市场          | 是   | Skill 发布、审核、分发                        |
| MCP Servers           | 是   | 外部工具提供商                                |
| 用户设备              | 部分 | 移动应用、桌面客户端                          |

### 1.3 超出范围

此威胁模型没有明确超出范围的内容。

### 2.2 数据流

| 流  | 源      | 目标    | 数据           | 保护           |
| --- | ------- | ------- | -------------- | -------------- |
| F1  | 频道    | Gateway | 用户消息       | TLS、AllowFrom |
| F2  | Gateway | Agent   | 路由的消息     | 会话隔离       |
| F3  | Agent   | 工具    | 工具调用       | 策略执行       |
| F4  | Agent   | 外部    | web_fetch 请求 | SSRF 阻止      |
| F5  | ClawHub | Agent   | Skill 代码     | 审核、扫描     |
| F6  | Agent   | 频道    | 响应           | 输出过滤       |

## 3. 按 ATLAS 战术分析威胁

### 3.1 侦察(AML.TA0002)

#### T-RECON-001: Agent 端点发现

| 属性             | 值                                      |
| ---------------- | --------------------------------------- |
| **ATLAS ID**     | AML.T0006 - 主动扫描                    |
| **描述**         | 攻击者扫描暴露的 OpenClaw Gateway 端点  |
| **攻击向量**     | 网络扫描、shodan 查询、DNS 枚举         |
| **受影响的组件** | Gateway、暴露的 API 端点                |
| **当前缓解措施** | Tailscale 认证选项、默认绑定到 loopback |
| **剩余风险**     | 中 - 公共 Gateway 可被发现              |
| **建议**         | 记录安全部署,在发现端点上添加速率限制   |

#### T-RECON-002: 频道集成探测

| 属性             | 值                                     |
| ---------------- | -------------------------------------- |
| **ATLAS ID**     | AML.T0006 - 主动扫描                   |
| **描述**         | 攻击者探测消息频道以识别 AI 管理的账户 |
| **攻击向量**     | 发送测试消息,观察响应模式              |
| **受影响的组件** | 所有频道集成                           |
| **当前缓解措施** | 无特定措施                             |
| **剩余风险**     | 低 - 仅发现的价值有限                  |
| **建议**         | 考虑响应时间随机化                     |

### 4.2 审核标记模式

`moderation.ts` 中的当前模式:

```javascript
// 已知不良标识符
/(keepcold131\/ClawdAuthenticatorTool|ClawdAuthenticatorTool)/i

// 可疑关键字
/(malware|stealer|phish|phishing|keylogger)/i
/(api[-_ ]?key|token|password|private key|secret)/i
/(wallet|seed phrase|mnemonic|crypto)/i
/(discord\.gg|webhook|hooks\.slack)/i
/(curl[^\n]+\|\s*(sh|bash))/i
/(bit\.ly|tinyurl\.com|t\.co|goo\.gl|is\.gd)/i
```

**限制:**

- 仅检查 slug、displayName、summary、frontmatter、metadata、文件路径
- 不分析实际 skill 代码内容
- 简单正则表达式容易通过混淆绕过
- 无行为分析
